# Videos

Esta carpeta contiene los videos originales que se reproducen durante el desarrollo local con `npm run dev`. Vite no los incluye en el build de producción.

Los archivos actuales suman aproximadamente 3.8 GB, así que no los copies a `public/` ni intentes desplegarlos junto con el sitio. Para reproducirlos en producción, súbelos a YouTube, Vimeo o un CDN/almacenamiento de objetos y cambia `videoType` y `video` en `js/projects.js`. Publica únicamente material que tengas derecho a mostrar.
