# Miniaturas

Las miniaturas actuales se generaron automáticamente como JPG a partir de los videos y se guardan en `public/videos/miniaturas/` para que Vite las copie al build. En `js/projects.js`, cada proyecto apunta a su miniatura correspondiente. Reemplázalas por imágenes seleccionadas manualmente si quieres elegir un fotograma distinto.
